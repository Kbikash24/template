# Online Kaksha - Next.js VersionA modern EdTech learning platform built with Next.js 16, React, and TypeScript. Features animated canvas background, 3D interactive elements, and a blend of free and premium educational content.## 🎨 Design Features- **Modern Design**: Dark Orange (#dc5f00) and Dark Sky Blue (#075985) color scheme- **Animated Background**: Particle system with connecting lines and mouse interaction- **Responsive**: Mobile-first design approach- **Smooth Animations**: Hover effects and transitions## 📦 Project Structure`onlinekaksha-nextjs/├── app/│   ├── globals.css       # Global styles with color variables│   ├── layout.tsx        # Root layout with Outfit font│   └── page.tsx          # Main page with all sections├── components/│   ├── BackgroundCanvas.tsx      # Animated particle background│   ├── NewNavbar.tsx            # Sticky navigation│   ├── NewHero.tsx              # Hero with profile image│   ├── AboutSection.tsx         # About section│   ├── FreeResourcesSection.tsx # Free learning materials│   ├── PremiumCoursesSection.tsx # Premium courses│   ├── TestimonialsSection.tsx  # Student reviews│   └── NewFooter.tsx            # Footer├── public/               # Static assets (add profile.png here)└── Configuration files`## 🚀 Getting Started`bashcd onlinekaksha-nextjsnpm installnpm run dev# Visit http://localhost:3000`**Important**: Add your profile image as `public/profile.png` or update the path in `NewHero.tsx`## 📄 Sections1. **Hero**: Welcome banner with profile image and stats2. **About**: Mission, founder info, key statistics3. **Free Resources**: PYQs, Quizzes, Notes, YouTube videos4. **Premium Courses**: 3 paid course packages (₹999-₹2,999)5. **Testimonials**: Student success stories6. **Footer**: Quick links and resources## 🎨 Color Scheme`css--primary: #dc5f00        /* Dark Orange */--secondary: #075985      /* Dark Sky Blue */--text-main: #0f172a      /* Slate 900 */--text-muted: #64748b     /* Slate 500 */`## 🔧 Tech Stack- Next.js 16.2 + React 18.3 + TypeScript 5- Canvas API for animations- Font Awesome 6.4 icons- Outfit font from Google Fonts## 📝 Customization- **Colors**: Edit `:root` variables in `app/globals.css`- **Content**: Edit individual component files- **Images**: Replace placeholder images with your own## 🏗️ Build`bashnpm run buildnpm start`## 📄 LicenseProprietary - Online Kaksha 2026
